🔐 CVCircle Extension Session Flow Test

This page helps test the session sharing between the CVCircle website and Chrome extension.

📋 Test Steps

Step 1: Check Extension Environment

Verify the extension is using the correct API URL and can detect the environment.

Step 2: Check Cookie Access

Test if the extension can access cookies from the CVCircle website.

Step 3: Test Session Detection

Check if the extension can detect an active session from cookies.

Step 4: Test API Authentication

Verify that the extension can make authenticated API requests using session cookies.

Step 5: Test Session Sync

Test the session synchronization between the website and extension.

🔧 Manual Tests

Perform these tests manually to verify the complete flow:

  1. Login Test: Go to www.cvcircle.io/sign-in and log in
  2. Extension Check: Open the extension popup and verify it shows you're authenticated
  3. Job Save Test: Go to a job site (LinkedIn, Indeed, etc.) and try to save a job
  4. Logout Test: Log out from the website and check if the extension shows you're logged out
