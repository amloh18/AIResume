## Chrome Web Store Privacy Form - Required Information

### Single Purpose Description (1000 characters max)

CVCircle Job Saver has a single, narrow purpose: to help users save job postings from major job sites (LinkedIn, Indeed, Glassdoor, and others) directly to their CVCircle dashboard for tracking and management. The extension extracts publicly visible job information (title, company, location, description) from job posting pages and saves it to the user's CVCircle account. This eliminates the need for manual data entry when tracking job applications across multiple platforms. The extension does not perform any other functions - it solely focuses on job saving and syncing with the CVCircle dashboard. All functionality is directly related to this single purpose of job application management.

### Permission Justifications (1000 characters max each)

#### activeTab Justification

The activeTab permission is essential for the extension's core functionality. When a user visits a job posting page on LinkedIn, Indeed, or other supported job sites, the extension needs to access the active tab's DOM to extract job information. This includes reading publicly visible page content such as job title, company name, location, salary range, job description, and job URL. The extension only accesses the tab when the user explicitly interacts with it (by clicking the extension icon or save button), ensuring minimal privacy impact. Without activeTab, the extension cannot read job details from the current page, which is the primary purpose of the extension.

#### storage Justification

The storage permission is required to maintain user session state and preferences locally within the extension. Specifically, it stores: (1) authentication session information to verify the user is logged into CVCircle, (2) cached user preferences such as API endpoint configuration (localhost vs production), (3) temporary UI state to prevent unnecessary API calls, and (4) extension settings like whether to show notifications. This data is stored locally in the browser's extension storage and is never transmitted to third parties. The storage permission enables the extension to function efficiently without requiring re-authentication on every use, improving user experience while maintaining security.

#### cookies Justification

The cookies permission is essential for seamless authentication with the user's CVCircle account. When a user logs into CVCircle in their browser, the website sets authentication cookies. The extension reads these cookies to verify the user's session, allowing it to authenticate API requests without requiring a separate login. This creates a seamless experience where users don't need to authenticate separately in the extension. The extension only reads cookies from the CVCircle domain (cvcircle.io) and does not access cookies from job sites. Without this permission, users would be required to log in separately in the extension, creating friction and a poor user experience.

#### identity Justification

The identity permission is used for secure authentication flow when users need to authenticate with their CVCircle account. While the extension primarily uses cookie-based authentication (reading existing session cookies), the identity permission provides a fallback mechanism for secure authentication if cookies are unavailable. It enables the extension to use Chrome's identity API for secure token exchange, ensuring that authentication credentials are handled securely through Chrome's managed authentication flow. This permission is used only when necessary and only for CVCircle authentication, not for any other purpose.

#### scripting Justification

The scripting permission is required to inject content scripts that enable the extension's core functionality on job sites. Specifically, it allows the extension to: (1) inject save buttons onto job posting pages, (2) extract job information from the page DOM, (3) inject the side panel interface that displays job details and saved jobs, and (4) modify page styling to integrate the extension UI seamlessly. Without scripting, the extension cannot add its interface elements or extract job data from pages. The extension only uses scripting on supported job sites and the CVCircle website, and only injects code that is necessary for job saving functionality.

#### sidePanel Justification

The sidePanel permission enables the extension to display a modern, accessible interface panel on job sites. When users click the extension icon or save a job, the side panel opens to show: (1) the current job's details for review before saving, (2) the user's saved jobs list and statistics, (3) application tracking information, and (4) controls to save, edit, or manage jobs. The side panel provides a non-intrusive way to interact with the extension without modifying the job site's page content. This permission is essential for the extension's user interface and is only used on supported job sites to provide job management functionality.

#### tabs Justification

The tabs permission is required to identify the current active tab and determine which job site the user is visiting. This allows the extension to: (1) detect when a user is on a supported job site and enable the save functionality, (2) extract the current page URL to save as the job posting link, (3) determine which content script to run based on the job site domain, and (4) open the side panel on the correct tab. The extension only accesses tab information (URL and title) to determine context and does not read or modify tab content beyond what is necessary for job saving. This permission is essential for the extension to function correctly across different job sites.

#### Host Permission Justification

Host permissions are required for the extension's single purpose of saving jobs from major job sites. The extension needs access to: (1) Job sites (LinkedIn, Indeed, Glassdoor, etc.) to extract publicly visible job information and display save buttons, and (2) CVCircle website (cvcircle.io) to authenticate users and sync saved jobs. The extension only accesses job sites when users explicitly visit them and only extracts publicly visible job posting information. It does not access any private user data from job sites. Access to CVCircle is necessary for authentication and data synchronization. The extension operates with minimal permissions, only accessing domains necessary for its core functionality of job saving and tracking. All host permissions are directly related to the extension's single purpose and cannot be reduced without breaking functionality.

### Remote Code Usage

**No, I am not using Remote code**

The extension does not load, execute, or reference any JavaScript or WebAssembly code from external sources. All code is bundled within the extension package. The extension does not use external script tags, external modules, or eval() functions. All functionality is implemented using local scripts included in the extension's package.
