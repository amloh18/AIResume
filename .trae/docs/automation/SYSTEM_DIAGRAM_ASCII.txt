## 6. Database Schema Relationships

```
users (1)
  │
  ├──< job_preferences (1:1)
  │
  ├──< automation_settings (1:1)
  │
  ├──< job_matches (1:N)
  │     │
  │     └──> jobs (N:1)
  │
  ├──< applications (1:N)
  │     │
  │     ├──> jobs (N:1)
  │     ├──> resume_versions (N:1)
  │     └──> cover_letter_versions (N:1)
  │
  └──< audit_logs (1:N, as actor)

jobs (1)
  │
  ├──< job_matches (1:N)
  │
  └──< applications (1:N)

admin_rules (singleton, no FK)

api_usage (time-series, no FK)
```

Key:
- `1:1` = One-to-One
- `1:N` = One-to-Many
- `N:1` = Many-to-One
- `──<` = has many
- `──>` = belongs to
