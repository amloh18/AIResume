# 🎥 Product Video Generation Guide

## Quick Start (Recommended)

### 1. **Screen Recording with Loom** (Easiest)
1. Go to [loom.com](https://loom.com)
2. Sign up for free account
3. Install Loom extension
4. Click "Record Screen" 
5. Follow the script below

### 2. **Video Script** (2-3 minutes)

#### **Opening (0-10 seconds)**
- "Create professional CVs in minutes with AI assistance"
- Show final CV result first (hook)

#### **Problem Setup (10-20 seconds)**
- "Tired of spending hours formatting CVs?"
- "Struggling to pass ATS systems?"

#### **Solution Demo (20-90 seconds)**
1. **Landing Page** (5s)
   - Show clean, professional landing page
   - Highlight "Get Started" button

2. **Sign Up Process** (10s)
   - Quick sign up flow
   - Email verification

3. **CV Creation** (30s)
   - Choose template
   - Fill in personal info
   - Add work experience
   - Show AI suggestions

4. **AI Features** (20s)
   - ATS optimization
   - Content suggestions
   - Format improvements

5. **Job Application Tracking** (15s)
   - Add job posting
   - Track application status
   - Show dashboard

6. **Final Result** (10s)
   - Download PDF
   - Show professional CV
   - Highlight key features

#### **Call to Action (90-120 seconds)**
- "Start building your professional CV today"
- "Join thousands of successful job seekers"
- Show sign-up button

### 3. **Recording Tips**

#### **Before Recording:**
- [ ] Clear browser cache
- [ ] Prepare test data (fake but realistic)
- [ ] Close unnecessary tabs
- [ ] Set screen resolution to 1920x1080
- [ ] Test audio levels

#### **During Recording:**
- [ ] Speak clearly and confidently
- [ ] Keep cursor movements smooth
- [ ] Don't rush through steps
- [ ] Show actual features, not just UI
- [ ] Use real data (names, companies, etc.)

#### **After Recording:**
- [ ] Trim unnecessary parts
- [ ] Add captions if needed
- [ ] Export in MP4 format
- [ ] Optimize file size (< 50MB)

### 4. **File Setup**

1. **Create video directory:**
   ```bash
   mkdir -p public/videos
   mkdir -p public/images
   ```

2. **Add video file:**
   - Save as `public/videos/product-demo.mp4`
   - Keep under 50MB for web optimization

3. **Add poster image:**
   - Create thumbnail: `public/images/video-poster.jpg`
   - Size: 1920x1080 or 16:9 ratio
   - Show key moment from video

### 5. **Alternative: Quick Mock Video**

If you want to test the component first:

1. **Use existing video:**
   - Download a sample MP4 from [Pexels](https://pexels.com)
   - Place in `public/videos/product-demo.mp4`

2. **Create poster image:**
   - Take screenshot of your app
   - Add text overlay: "CV Circle Demo"
   - Save as `public/images/video-poster.jpg`

### 7. **Optimization Tips**

#### **Video Specifications:**
- **Format**: MP4 (H.264)
- **Resolution**: 1920x1080 (1080p)
- **Frame Rate**: 30fps
- **Duration**: 60-120 seconds
- **File Size**: < 50MB
- **Aspect Ratio**: 16:9

#### **Web Optimization:**
- Compress with [HandBrake](https://handbrake.fr)
- Use [Cloudinary](https://cloudinary.com) for hosting
- Add lazy loading to video component

### 8. **Testing Checklist**

- [ ] Video loads on desktop
- [ ] Video loads on mobile
- [ ] Controls work properly
- [ ] Poster image displays
- [ ] Responsive design works
- [ ] Fast loading time (< 3 seconds)
